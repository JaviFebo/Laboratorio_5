# Laboratorio_5
Este repositorio contiene el código para el laboratorio 5 de programación bajo plataformas abiertas.
El código incluye la estructura de nodos para construir una lista enlazada y las siguientes funciones relacionadas a la lista enlazada:
 - Añadir nodo al inicio
 - Añadir nodo al final
 - Añadir nodo en una posición específica
 - Eliminar nodo por dato
 - Buscar nodo por dato
 - Imprimir lista

Para compilar ejecute el comando:
make

Para ejecutar el programa ejecute el comando:
./main
